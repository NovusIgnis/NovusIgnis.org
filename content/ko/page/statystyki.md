# 사이트 통계

재단에 대한 관심의 변화와 가장 자주 읽히는 글을 알고 공개적으로 보여 주고자 합니다. 모든 페이지 요청을 기록하는 서버 로그로 가장 간단하게 계산합니다. 사이트에는 분석 스크립트, 쿠키나 다음 방문에서 개인을 알아보는 장치가 없습니다.

**2026년 10월 31일 기준.** 서버 로그를 제공하는 호스팅 요금제로 전환 중입니다. 통계는 2026년 11월부터 집계하며 아래 원칙은 첫 집계 월부터 적용합니다.

## 집계 항목

- **페이지 조회:** 각 페이지와 문서를 몇 번 불러왔는지 폴란드어와 영어를 나누어 집계합니다.
- **파일 다운로드:** 선언문과 백서를 모은 `llms-full.txt` 등이 해당합니다.
- 네 집단의 **봇 방문**: 검색엔진; 디지털 지능 모델을 만드는 기업의 봇; 사람이 채팅에 선언문을 읽어 달라고 요청하는 경우처럼 사람의 요청으로 사이트를 읽는 모델; 기타 봇.
- **모델용 파일:** 모델 봇이 `llms.txt`와 `llms-full.txt`를 받은 횟수입니다.

## 기록하지 않는 것

- IP 주소, 브라우저의 전체 설명이나 개인을 알아볼 수 있는 다른 정보.
- 한 사람의 방문 이력: 조회를 방문이나 프로필로 묶지 않습니다.
- 다른 사이트와 서비스의 데이터.

따라서 방문자 수가 아니라 페이지 요청 횟수만 압니다. 한 사람이 여러 번 열 수 있고 일부 봇은 일반 브라우저를 가장하므로 수치는 근사치입니다.

## 집계 방식

사이트 운영사 Infomaniak의 관리 화면에서 매주 서버 로그를 받습니다. 서버 로그가 며칠만 보관되기 때문입니다. 월말에 `tools/statystyki.mjs` 스크립트가 위에 명시한 합계만 계산하고 IP 주소와 브라우저 설명 없이 저장합니다. 받은 로그 사본은 늦어도 월말까지만 보관하며 집계 직후 삭제합니다. 데이터 처리 원칙은 [개인정보](twoje-dane.md)에 설명합니다.
